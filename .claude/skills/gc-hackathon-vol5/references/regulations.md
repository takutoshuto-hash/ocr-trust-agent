> 以下は参加規約（確定版）およびLP掲載のルールに基づく。

## 参加資格（確定・規約第3条）

- 日本国内に居住する18歳以上の個人、または個人により構成されるチーム
- チームとして参加する場合、チームメンバー全員が連帯して規約上の義務を負う
- 以下の者は参加できない:
  - 政府機関の職員
  - 企業の意向によって当該企業の代表として選出された個人
  - 協賛者、サポートスポンサーおよび主催者の従業員、その関係者および家族
  - 本ハッカソンの企画、運営に直接関与する者
  - その他、主催者が不適切と判断した者
- 「政府機関の職員」には非常勤・兼業（フリーランス）も該当し、参加できない
- Google Cloud Innovatorsプログラムへの参加は不要

## 参加形態（確定）

- 個人またはチームで参加できる。チームの場合、代表者・メンバーともに参加登録が必要
- 複数のプロジェクトへの参加は可能（チーム参加しながら、個人で別プロジェクトの提出も可能）
- チームビルディングを希望する場合はDiscordに招待されるので、申し込みフォームで意向を回答する

## 開発プロジェクトの条件（確定・規約第4条）

提出物は以下の条件を満たす必要がある。

- **指定のGoogle Cloud AI製品およびアプリケーション関連製品を用いること**（下記リスト）
- 開発者が自己の権利で使用できるツールを使用すること
- **日本語で記載すること**

### （必須）Google Cloud アプリケーション実行プロダクト

以下のいずれかを1つ以上、アプリケーションの実行に使用すること。

- App Engine
- Compute Engine
- Google Kubernetes Engine（GKE）
- Cloud Run
- Cloud Run functions（旧 Cloud Functions）
- Cloud TPU / GPU

### （必須）Google Cloud AI 技術

以下のいずれかを1つ以上使用すること。

- Gemini Enterprise Agent Platform（旧称 Vertex AI。Model Garden、Vector Search などを含む）
- Gemini API（Gemini Enterprise Agent Platform 経由での利用を推奨）
- Gemma
- Nano Banana
- Agent Development Kit（ADK）
- Speech-to-Text / Text-to-Speech API
- Vision AI
- Natural Language AI
- Translation AI

### （任意）その他の技術

Flutter / Firebase を利用しているプロジェクトは、その旨を申告する。

### （任意）Supportスポンサーが提供する技術

Supportスポンサー提供のサービス・特典はLPの推奨サービス欄を参照。**これらのサービスの利用の有無は審査には影響しない**。

### 条件判定のFAQ（確定）

- Gemini API は AI Studio からの**直接利用でも条件を満たす**。ただしGoogle Cloudアプリケーション実行プロダクトの利用は別途必須
- Cloud Functions for Firebase・Firebase App Hosting は**実行プロダクトの条件を満たす**
- Firebase 経由の Gemini API 利用は**AI技術の条件を満たす**
- Firebase Extension のみでは**実行プロダクトの条件を満たさない**
- ローカル環境のみでの動作は不可。**Google Cloud へのデプロイが必要**
- Web/ネイティブアプリの指定はない（ネイティブの場合は可能な限りWeb版を公開。詳細は [faq.md](faq.md) 参照）

## 審査基準（確定・規約第7条）

1. **課題の新規性と解決策の有効性**: 多くの人が抱えながらも、いまだ解決策が与えられていない課題を発見できているか。提案されたソリューションがその課題の核心に効果的に対処し、実質的な価値をもたらしているか
2. **自律性・エージェントらしさ**: 単純な自動化を超え、状況を判断しながら自律的に行動するエージェントとして設計されているか。その自律性が適切に管理・制御されており、可観測性やセキュリティへの配慮を持った、信頼できる動作をするか
3. **実装品質と拡張性**: アイデアをどれだけ高い品質で実現できているか。必要なツールを適切に活用し、拡張性・運用性・費用対効果を考慮した、実用に耐えるソリューションを構築できているか

## 提出物・知的財産に関する主な規定（確定・規約第5・6条）

- 提出物は参加者が独自に制作したものであり、第三者の権利を侵害しないこと
- オープンソースソフトウェアを使用する場合、ライセンス条件を遵守し、提出物においてライセンス情報を明記すること
- 提出物の著作権・知的財産権は参加者に帰属する。主催者等は審査・評価・プロモーション目的に限り提出物を無償で使用できる
