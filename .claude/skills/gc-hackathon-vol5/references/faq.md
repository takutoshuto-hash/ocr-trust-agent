# FAQ（確定・LP掲載）

一次情報: https://zenn.dev/hackathons/google-cloud-japan-ai-hackathon-vol5

## エントリーについて

**Q: エントリーまでの流れは？**
A: 公式ページの「申し込む」からZennアカウントでログインしてエントリーする。エントリー後、ダッシュボードに表示される参加者情報フォーム（Googleフォーム）に氏名・所属などを入力すると参加登録完了となる。

**Q: チームで参加する場合、メンバー全員のエントリーが必要？**
A: 必要。代表者・メンバーともに参加登録する。

**Q: エントリー後は何をすればいい？**
A: 参加者情報フォームの入力が完了すると、プロジェクトを作成できるようになる。チームの場合は代表者がプロジェクトを作成し、エントリー済みメンバーを招待する。

**Q: チームメンバーの追加・脱退はいつまでできる？**
A: 提出締切（2026年10月15日（木）23:59）まで可能。提出後も締切までは変更できる。締切後は不可。

**Q: 参加を取り消したくなったら？**
A: 取り消し操作は無い。プロジェクトを提出しないまま締切を迎えて問題なく、ペナルティも無い。

## 参加資格について

**Q: 非常勤や兼業（フリーランス）でも「政府機関の職員」に該当する？**
A: 該当するため参加できない。

**Q: 申し込み後にチームを組成できる？**
A: Discordの専用チャンネルでメンバー募集・チームビルディングができる。スキル面の参加条件は無い。

**Q: 同一メンバーで複数のプロジェクトを提出できる？**
A: 可能。ダッシュボードでプロジェクトをそれぞれ作成し個別に提出する。複数プロジェクトへの関与が審査で不利になることも無い。

**Q: ミニハッカソンだけの参加でもよい？**
A: よい。ミニハッカソンのみの参加が可能で、その成果をもって本戦へ進める。

## 提出物・技術条件について

**Q: WEBアプリかネイティブアプリかの指定はある？**
A: どちらでも可。ただし開発プロジェクト条件（Google Cloudアプリケーション実行プロダクトの利用）は満たすこと。

**Q: ネイティブアプリの場合、デプロイURLには何を書く？**
A: 可能な限りWeb版を公開しそのURLを記載する（Webで実現が難しい機能は未搭載でも可）。Web版が難しい場合は、ネイティブアプリである旨と事情を「動作確認の方法」項目に記載する。審査はデモ動画中心に行われる。

**Q: ローカル環境で動けばよい？**
A: 不可。Google Cloudへのデプロイが必要。dev環境でも動作確認できれば問題ない。

**Q: Gemini API は AI Studio からの直接利用でも条件を満たす？**
A: 満たす。ただしGoogle Cloudアプリケーション実行プロダクトの利用は別途必須。

**Q: Cloud Functions for Firebase / Firebase App Hosting は実行プロダクトの条件を満たす？**
A: どちらも満たす。

**Q: Firebase 経由の Gemini API 利用はAI技術の条件を満たす？**
A: 満たす。

**Q: Firebase Extension のみで実行プロダクトの条件を満たす？**
A: 満たさない。

**Q: プロジェクトコードはどのレベルまで含める？**
A: 可能な範囲でよい。ただし、どの部分を開発したか・パッケージ化している部分はどこかなどの構成説明は必ず加え、主要機能がモックではなく実装されていることが分かる程度にリポジトリに含める。

**Q: Googleアカウントは企業・個人どちらがよい？**
A: 企業アカウントはセキュリティポリシーでGemini等に接続できない場合があるため、個人アカウントを推奨。

**Q: 提出後も開発を続けたい**
A: 審査のため提出締切から12月1日（最終審査）までは提出リポジトリに修正を加えない。継続開発する場合はタグかブランチを切る。

**Q: 提出後に記事やリポジトリ、動画を修正してもいい？**
A: 提出時点の成果物を評価するため、提出後の修正は控える。

**Q: ハッカソン以前から開発していたプロジェクトを提出してもいい？**
A: 開始時点で一定進捗していたプロジェクトの提出は、公平性の観点から控える。

## スケジュールについて

**Q: 参加登録・提出の締切は当日の何時まで？**
A: 2026年10月15日（木）23:59まで。

**Q: 審査に通過しなかった場合、連絡はある？**
A: ある。提出されたすべてのプロジェクトに、1次審査後・2次審査後にそれぞれ通過・落選の連絡が届く。
